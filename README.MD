# Развёртывание и обновление через ИИ-агента

Подробная пошаговая инструкция для агента — [DEPLOY.md](DEPLOY.md). Можно просто попросить ИИ-агента:

- «Разверни AI_1C по `DEPLOY.md` в `<каталог>`» — развернёт навыки, docs и правила в новый или существующий проект 1С (настройка `.v8-project.json`, подключение базы, выгрузка исходников).
- «Обнови AI_1C по `DEPLOY.md`» — обновит набор из этого репозитория, не затрагивая `.v8-project.json`, `src/`, `TASKS/`, `build/` и локальные разделы `AGENTS.md`.

# Быстрый старт (вручную)
1. Копирование этого проекта (или `git clone https://github.com/smirnov0ser/AI_1C.git "<каталог>"`)
2. Создать тестовую базу для AI. Если файловая - внутри папки проекта (для упрощения прав доступа)
3. Выгрузить файлы конфигураций и расширений в файлы в src (в отдельные папки)
4. Обновить .v8-project.json под свой проект (шаблон и описание полей — в DEPLOY.md и docs/v8-project-guide.md)
5. Убедиться что AGENTS.md и Правила разработки и доработки конфигураций.md добавлен в файлы инструкций, и skills видны
6. Обновлять набор при выходе новых версий — по разделу «Обновление» в DEPLOY.md (исходные навыки: https://github.com/Nikolay-Shirokov/cc-1c-skills)
7. Установить MCP для чтения данных из 1С (опционально, https://github.com/feenlace/mcp-1c) 
Для установки попросить ИИ агента: установи mcp-1c, следуя инструкциям из .\tools\mcp-1c-setup.md
