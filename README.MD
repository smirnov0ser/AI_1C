Вот действия по подключению базы 1с к AI Разработке:

# Быстрый старт
1. Копирование этого проекта
2. Создать тестовую базу для AI. Если файловая - внутри папки проекта (для упрощения прав доступа)
3. Выгрузить Файлы конфигураций и расширений в файлы в scr (в отдельные папки)
4. Обновить .v8-project.json под свой проект
5. Убедиться что AGENTS.md и Правила разработки и доработки конфигураций.md добавлен в файлы инструкций, и skills видны
6. Обновить при необходимости  
https://github.com/Nikolay-Shirokov/cc-1c-skills - skills и docs
7. Установить MCP для чтения данных из 1С (опционально, https://github.com/feenlace/mcp-1c) 
Для установки попросить ИИ агента: установи mcp-1c, следуя инструкциям из .\tools\mcp-1c-setup.md
